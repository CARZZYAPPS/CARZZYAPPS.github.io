How to Play

Setup:

  • Create teams using the Add/Edit Teams button.
    • asdk) to customize categories and clues.

Gameplay:

  • Click Start Game to randomly select a starting team.
  • Teams take turns choosing a clue from the board.
  • When a clue is opened, Jeopardy music plays for 32 seconds.
  • Click Show Answer to reveal the answer and then mark Correct or Wrong.
  • If the timer ends before Show Answer is clicked, the answer auto-reveals and is auto-marked Wrong.
  • Clues can be reopened later, but they cannot be scored again.

Resetting:

  • Use Reset Board in Editor Mode to clear used clues and scores mid-game.
  • When all clues are used, a Reset Board button appears outside Editor Mode.
  • Reloading the page does not reset the board; state is saved.
Click any clue to edit it while in Editor Mode.
